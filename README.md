# Midnight Eclipse

A glass status bar for [Zebar](https://github.com/glzr-io/zebar), built for the [komorebi](https://github.com/LGUG2Z/komorebi) tiling window manager on Windows 11.

Work in progress.

## Try it

Copy `pack/` to `%USERPROFILE%\.glzr\zebar\midnight-eclipse` and start the `bar` widget from Zebar's settings. The bar expects komorebi in its default location, `C:\Program Files\komorebi\bin`.
